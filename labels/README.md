# labels/ — разметка

- `reference.csv` — разметка сценарных роликов организаторов (эталон). Формат — `docs/ACCURACY.md` §3.
- `hidden.csv` — разметка скрытого набора, появится после фиксации результата.

В файлах только время, метки и положение человека в кадре словами («слева», «в центре»), без кадров и примет внешности. Файлы `*.csv` в git не попадают.
