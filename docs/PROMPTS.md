# Промпты для Claude Code: по шагам

Копируй их по одному. К следующему шагу переходи, только когда предыдущий проверен и закоммичен.
Приоритеты: корректность → устойчивость → стоимость → внешний вид (`docs/ACCURACY.md`, `docs/DESIGN.md`).

## Как работать

- **Режим.** Для первого промпта включи **Plan** (переключатель режимов рядом с кнопкой отправки). Для реализации — **Accept edits**: правки файлов и простые команды вроде `mkdir`, `touch`, `mv` применяются сами, а на остальные команды Claude спрашивает разрешение. **Auto** и **Bypass permissions** не включай.
- **Разрешения.** Читай каждую команду. Разрешай `conda run … python`, `pytest`, `pip install`, `git add`/`git commit`, `ffprobe`. Запуск нашего конвейера на `private/` тоже можно: видео обрабатывается локально. Отказывай во всём, что показывает Claude содержимое видео объекта (кадры, картинки), копирует его из `private/` или отправляет файлы в интернет.
- **Точность — только с цифрами.** Если изменение может повлиять на точность, проси таблицу метрик «до» и «после» на одном и том же наборе.
- **Внешний вид проверяй только на публичных роликах.** Claude может смотреть скриншоты интерфейса и оверлея, но только пока в них открыто видео из `data/public/`, а не с объекта.
- **Видео с объекта смотришь только ты** — в QuickTime Player или в своём браузере, не в панели браузера Claude. В чат его не загружай.
- **Не верь слову «готово».** Проси показать вывод тестов и цифры.
- **Ошибки** вставляй целиком, вместе с трассировкой (traceback).
- **Если Claude ушёл не туда** — останови и поправь. Если две поправки подряд не помогли, начни новую сессию и поставь задачу точнее.
- **Одна сессия — одна задача.** Контекст между сессиями сохраняется в файлах: CLAUDE.md, docs/, код.
