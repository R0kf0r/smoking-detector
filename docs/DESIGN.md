# DESIGN: внешний вид видео, интерфейса и графиков

## Для кого и зачем

- **Зрители:** жюри «Видеофор» на защите (5 минут доклад и 5 минут вопросы) и оператор видеонаблюдения.
- **Главная задача экрана:** за три секунды показать, кто отмечен, когда и почему. Доказательство важнее украшений.

Ориентир — синтетический макет `docs/design_reference.png` (без реальных записей): состояния рамок, ярлыки, полоса времени и «след жеста».

## Главная идея: «след жеста»

Под видео идёт график расстояния «кисть — рот» выбранного человека во времени. Паузы у рта подсвечены и подписаны: «цикл 1», «цикл 2». Событие показано отрезком. Это правило со слайда 5, нарисованное на данных: зритель видит, почему система сработала. Это единственная яркая деталь, всё остальное спокойное.

## Токены

**Цвета.** Тема тёмная: видео на тёмном фоне читается лучше. Заранее проверить на проекторе.

| Токен | Hex | Где |
|---|---|---|
| Графит (фон) | `#1B242B` | фон приложения |
| Поверхность | `#24313A` | панели, карточки событий |
| Линия | `#33424C` | сетка графиков, разделители |
| Текст основной | `#E8EEF1` | заголовки, значения |
| Текст вторичный | `#9FB0BA` | подписи, линия сигнала на графике |
| Сталь | `#8FA3B0` | обычный человек в кадре |
| Натриевый янтарь | `#F2B544` | рука у лица, кандидат (цвет уличных фонарей) |
| Сигнальный кармин | `#E5484D` | событие «похоже на курение» |

- Янтарь и кармин проверены валидатором: различимы и при обычном зрении (ΔE 24,7), и при дейтеранопии (ΔE 18,8).
- Состояние никогда не передаётся только цветом: рядом всегда есть слово или счётчик.
- Зона интереса не получает отдельного цвета. Всё вне зоны затемняется на 35%, граница — тонкий пунктир цвета основного текста с прозрачностью 60%.

**Шрифт:** Golos Text (Google Fonts, лицензия OFL, полная кириллица) — и в интерфейсе, и в тексте на видео. Файлы уже лежат в `static/` (веса 400 и 600). В шрифте есть табличные цифры: в интерфейсе включать `font-variant-numeric: tabular-nums`, чтобы таймкоды не прыгали. На видео таймеры ставить в плашку фиксированной ширины.

**Формы:** скругление 6 px у плашек и карточек, 0 у рамок людей. Теней и градиентов нет.

## Видео с отметками (оверлей)

- **Рамка человека:** 2 px, со сглаживанием (`cv2.LINE_AA`). Цвет по состоянию: сталь → янтарь (рука у лица) → кармин (событие). Дрожание рамки сглаживать (EMA).
- **Ярлык над рамкой:** плашка с ID и состоянием словами — «ID 7», «рука у лица 1,8 с», «похоже на курение 0,91».
- **Счётчик циклов:** под ярлыком две точки (○○ → ●○ → ●●).
- **Таймер паузы:** тонкая янтарная дуга у рта, заполняется от 0 до 5 с.
- **Полоса времени внизу кадра:** высота 3% кадра. Серая дорожка, янтарные риски циклов, карминовые отрезки событий, светлая риска текущего момента.
- **Штатные надписи камеры** (дата вверху справа, название внизу слева) не перекрывать.
- **Текст рисовать через Pillow шрифтом Golos Text.** `cv2.putText` не умеет кириллицу и выглядит угловато.
- **Размеры задавать в долях высоты кадра** (текст ≈ 2,2%), чтобы на разных камерах всё выглядело одинаково.
- **Экспорт:** H.264 (mp4), чтобы ролик играл в браузере.
- **Где хранить:** обработанные ролики с объекта — только в `private/renders/`.

## Интерфейс (Streamlit)

```
┌──────────────────────────────────────────────┬────────────────────────┐
│ Камера [выбор]   Клип [выбор]   [Обработать] │ События: 3             │
├──────────────────────────────────────────────┤ ┌────────────────────┐ │
│                                              │ │ 00:41–00:58  ID 7  │ │
│              видео с отметками               │ │ 2 цикла, 0,91      │ │
│                                              │ │ VLM: сигарета      │ │
│                                              │ └────────────────────┘ │
├──────────────────────────────────────────────┤ ┌────────────────────┐ │
│ След жеста: ID 7                             │ │ 02:10–02:31  ID 3  │ │
│ ‿‿⌒⌒‿‿⌒⌒‿   цикл 1   цикл 2   [событие]      │ └────────────────────┘ │
├──────────────────────────────────────────────┤ [Скачать события]      │
│ Полоса клипа: события и кандидаты            │ [Скачать manifest]     │
└──────────────────────────────────────────────┴────────────────────────┘
```

- **Тема** задаётся в `.streamlit/config.toml`: `base = "dark"`, цвета из токенов. Шрифт подключается через `[[theme.fontFaces]]` и `[server] enableStaticServing = true`, файлы шрифта лежат в `static/` (нужен streamlit ≥ 1.45; свериться с документацией Streamlit о шрифтах).
- **График «след жеста»** строится в Plotly.
  - Одна линия цвета вторичного текста.
  - Паузы у рта — янтарная заливка (около 22%).
  - Событие — карминовая полоса над графиком с подписью времени, а не заливка: заливки, наложенные друг на друга, смешиваются в грязный цвет.
  - Пороги гистерезиса — пунктир.
  - Подписи «цикл 1», «цикл 2» стоят прямо на графике.
  - Подсказка при наведении: время, расстояние, состояние.
  - Легенды нет: линия одна, её называет заголовок. Ось Y одна.
- **Карточки событий:** время, ID, число циклов, уверенность, вердикт VLM. Клик по карточке перематывает видео к началу события.
- **Пустое состояние:** «Загрузите ролик и маску зоны — события появятся здесь».
- **Тексты:**
  - кнопки называют действие: «Обработать ролик», «Скачать события»;
  - никакого капслока и лишних подписей над блоками;
  - между значениями не ставить «·» и не добавлять «→» к кнопкам.
- **Сеть:** интерфейс ничего не грузит из интернета во время работы, обработка только локальная.

## Отчёт и презентация

- **Цвета и шрифт** — те же, что в интерфейсе и на видео.
- **Таблица по сценариям P01–N08:** найдено, пропущено, ложное срабатывание.
- **График «порог → precision, recall, F1»** на эталоне с отмеченной рабочей точкой. Три линии с подписями прямо на них, одна ось Y.
- **Два примера «следа жеста»:** позитив и сложный негатив (питьё). Второй показывает, как его отсекла проверка VLM.
- **Кадры с объекта** показываем только организаторам в рамках сдачи, нигде не публикуем.
