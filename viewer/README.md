# Просмотрщик

Локальный веб-интерфейс: выбрать ролик (эталон, скрытый набор) или перетащить свой файл → прогнать
конвейер → смотреть видео с отметками, «след жеста» с переходом по клику, события, циклы, ответы VLM,
время обработки и вердикт по разметке.

```bash
bash viewer/start.sh        # откроется http://127.0.0.1:8765
```

- Только стандартная библиотека Python; запускается в том же окружении `smoke`.
- Слушает 127.0.0.1: с других компьютеров недоступен, ролики не покидают этот Mac.
- Обработка — тот же `python -m smokedet.run` с тем же `configs/default.yaml` (тег `freeze-v1`).
  Если ролик уже прогоняли, поза и ответы VLM берутся из кэша `results/cache/` — остаётся только рендер.
- Пишет только в `private/viewer/` (загрузки и результаты) и в общий кэш; `results/hidden` не трогает.
- Пока идёт прогон скрытого набора (`hidden.sh`), новую обработку не запускает, смотреть готовое можно.
- Просмотрщик — инструмент для просмотра, к замороженному конвейеру не относится и предсказаний не меняет.
